## <#1462895580064911522> — Data Mixing Methodology

yurusankyo is [preparing an arXiv paper](https://discord.com/channels/1354881461060243556/1462895580064911522/1572772605373448193) cleaning up the parametric modeling and regression approach used for data mixing so far. A key open question is whether curriculum learning improves over static mixtures — results so far haven't shown that, possibly due to the data pools (Dolma 3, Dolmino) and the BPB-based optimization objective. yurusankyo noted the [Ripple-65B graph suggests](https://discord.com/channels/1354881461060243556/1462895580064911522/1572778401326956655) you should "just benchmaxx the base model," but getting strong signal from small-scale runs remains the core challenge. db [tested an eval-selection heuristic](https://discord.com/channels/1354881461060243556/1462895580064911522/1573717723266154527) using the highest-SNR smooth proxy (HellaSwag gold log-prob) on DataDecide, finding it only predicted the 1B winner 57% of the time vs 82% for the full 10-task average. yurusankyo [responded](https://discord.com/channels/1354881461060243556/1462895580064911522/1573877056893354151) with guidance on handling training-seed noise in eval comparisons.
